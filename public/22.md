# AWS LambdaのPython Runtimeを3.9から更高バージョンにアップグレードする手順

現在Python 3.9を使用しており、更高バージョン（3.10、3.11または3.12）にアップグレードする必要がある場合の安全な手順です。

## 1. バージョン選択と事前準備

**サポートされているPythonバージョン**:
- Python 3.10（推奨）
- Python 3.11（最新安定版）
- Python 3.12（最新版ですが、ライブラリのサポートが不十分な可能性あり）

**準備作業**:
1. Lambdaコンソールで現在の関数のバージョンスナップショットを作成（Actions > Publish new version）
2. 現在の設定を記録（メモリ、タイムアウト、環境変数、VPC設定など）
3. janrainライブラリの互換性を確認:
   ```bash
   pip download janrain --python-version 3.10 --platform manylinux2014_x86_64
   ```

## 2. アップグレード手順

### 方法1: コンソールを使用した段階的アップグレード（推奨）

1. **テスト用関数の作成**:
   - Lambdaコンソールに移動
   - 対象関数を選択 > Actions > Clone
   - `[元の関数名]-upgrade-test`という名前で作成
   - RuntimeをPython 3.10/3.11に変更

2. **手動テスト**:
   - テストイベントを使用して基本機能を検証
   - CloudWatchログを確認（/aws/lambda/[関数名]）

3. **本番環境のアップグレード**:
   - 元の関数に戻る
   - Configuration > Runtime settings > Edit
   - 新しいPythonバージョンを選択
   - 保存

### 方法2: AWS CLIを使用した精密制御

```bash
# 1. コードと依存関係を更新
zip -r function.zip ./*  # 更新された依存関係を含める

# 2. 関数設定を更新
aws lambda update-function-configuration \
  --function-name your-function \
  --runtime python3.10  # または python3.11

# 3. コードを更新（必要なら）
aws lambda update-function-code \
  --function-name your-function \
  --zip-file fileb://function.zip
```

## 3. 検証と監視

1. **即時検証**:
   - 関数をトリガーして結果を確認
   - CloudWatchログで例外を確認

2. **重要なチェックポイント**:
   - Janrainライブラリの初期化が正常か
   - インポートしているサードパーティライブラリが互換性があるか
   - 日付時刻処理（Python 3.9+で変更あり）
   - Pythonの内部実装に依存するコード

3. **監視指標**（最低24時間）:
   - エラーレート（Errors metric）
   - 実行時間（Duration metric）
   - メモリ使用量（Memory usage metric）

## 4. ロールバック手順

問題が発生した場合の即時ロールバック:

```bash
# 前の動作バージョンに戻す
aws lambda update-function-configuration \
  --function-name your-function \
  --runtime python3.9

# または公開バージョンに戻す
aws lambda update-alias \
  --function-name your-function \
  --name PROD \
  --function-version バックアップしたバージョン番号
```

## 5. 特別な注意事項

1. **Janrainライブラリの互換性**:
   - 新しいPythonバージョン用のjanrainパッケージがあるか確認
   - janrainライブラリのバージョンアップが必要な場合:
     ```bash
     pip install --upgrade janrain -t ./package
     ```

2. **Pythonバージョンの差異**:
   - Python 3.10+: 型チェックがより厳格に
   - Python 3.11+: 例外処理の変更あり
   - 非推奨機能を使用していないことを確認

3. **依存関係のビルド**:
   - Lambda Layersを使用している場合、レイヤーも新しいバージョンと互換性があることを確認
   - 依存関係の再ビルドが必要な場合:
     ```bash
     pip install -r requirements.txt --target ./package --platform manylinux2014_x86_64 --python-version 3.10
     ```

まずPython 3.10にアップグレードし、安定してから3.11を検討することをお勧めします。これによりリスクをより制御できます。
