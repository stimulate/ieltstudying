# Windows 11 移行ガイド

Created by: Wah Yuk

### **アップグレードの背景**

現在利用している`Windows 10`は、**2025年10月14日をもってマイクロソフト社の公式サポートが終了**します。サポート終了後は、セキュリティ更新プログラムや技術的なサポートが提供されなくなり、ウイルス感染や情報漏洩などのリスクが著しく高まります。
このため、企業のオフィス環境におけるセキュリティと安定性を確保する目的で、全社の利用デバイスに対し、物理端末（シンクライアント）とクラウド環境（RDP）の両方で`Windows 11`へのアップグレードを実施いたします。

### **アップグレードの進め方**

今回のアップグレードは、物理端末とクラウド環境の**二段階**で実施します。

**1. 物理端末（お手元のPC）のアップグレード【要予約・ご対応必須】**

物理端末のアップグレードは、ITサポート担当者が専門のデバイスを用いて一台ずつ行います。

- **実施期間:** 8月中旬までの完了を予定しています。
- **予約方法:** 全社に送付される予約案内のメールをご確認ください。メール内のリンクから`Microsoft Bookings`の予約ページにアクセスし、ご都合のよい日時をご予約ください。
- **【最重要】データバックアップのお願い:**
    - アップグレード作業に伴い、**物理端末のローカルディスク（デスクトップやドキュメントフォルダなど）に保存されているファイルはすべて削除されます。**
    - 作業前までに、**必ず個人のOneDriveへファイルのコピー・保存**をお願いいたします。
    - なお、Windows App（RDP接続）で利用しているクラウド上のWindowsシステム内のデータ（ファイル、設定など）が影響を受けることはなく、削除もされません。
- **アップグレード当日の流れ:**
    1. 予約した日時に、現在ご使用中のPCを**南青山オフィス**までお持ちください。
    2. 作業期間中、代替機として共用PCをお貸し出しします。共用PCは、ご自身の会社用メールアドレスとパスワードでログインして、物理端末およびWindows App（RDP）をご利用いただけます。
    3. アップグレード作業には**2時間～1日程度**かかる見込みです。
    4. 作業が完了しましたら、メールにてお知らせいたします。通知を受け取り次第、速やかにPCの交換をお願いいたします。

**2. クラウド環境（RDP）のアップグレード**

物理端末のアップグレードが全社で完了した後、管理者が遠隔でクラウド環境のアップグレードを一括して実施します。こちらは皆様の物理的な作業は不要です。8月中の完了を予定しております。

### **Windows 10からの変更点**

---

本アップグレードでは、一般的な Windows 11 Pro ではなく、**Windows 11 IoT Enterprise 24H2（OS Build 2610.4484）** を導入しています。

このバージョンは、以下のような特徴を持つ**企業向けの軽量版 Windows**です：

- **Thin Client や 組み込み端末、産業用PC 向けに最適化されたエディション**
- 一般的な Windows 11 Pro に比べて、**UI（ユーザーインターフェース）や初期設定が異なる**

### **1. スタートメニューとタスクバー**

最も大きな変化は、画面下部のタスクバーとスタートメニューです。

- **Windows 10:** スタートメニューには「ライブタイル」があり、情報が動的に表示されました。
- **Windows 11:** スタートメニューはシンプルになり、「ピン留め済」アプリと「おすすめ」セクションに分かれています。ライブタイルは廃止されました。
- タスクバーには初期状態で **［エクスプローラー］［Edge］ボタン** が表示されております
- ［設定］アプリのショートカットは **スタートメニューには表示されていません** → 以下の方法で開く：
    
    **設定アプリの開き方：**
    
    - `Win + X` → メニューから［設定］を選択
    - `Win + A` → クイック設定右下の歯車ボタン（⚙️）をクリック

**【ポイント】**

- よく使うアプリ（Word, Excel, Chromeなど）は、新しいスタートメニューで右クリックし、「スタートにピン留めする」を選択しておくと、素早くアクセスできて便利です。
- タスクバーの配置は、`「設定」>「個人用設定」>「タスクバー」>「タスクバーの動作」`から左揃えに変更できます。

### **2. エクスプローラー**

ファイルの閲覧や整理に使うエクスプローラーも新しくなりました。

- **Windows 10:** 上部に「リボン」と呼ばれる詳細なメニューがありました。
- **Windows 11:** **タブ式ホーム画面**。エクスプローラーで複数のフォルダをタブで開けるようになりました。複数の場所にあるファイルを同時に参照しながら作業する際に非常に便利です。

**【ポイント】**

- **ショートカットキーの活用:** `Ctrl + C`（コピー）、`Ctrl + V`（貼り付け）、`Fn + F2`（名前の変更）などのショートカットキーを覚えると、右クリックメニューの変更に影響されず、これまで通り素早く操作できます。

### **3. システム設定の変更点：クイック設定と通知センター**

音量やネットワーク、明るさなどの設定方法が変わりました。

- **Windows 10:** タスクバー右下のアイコンをクリックすると、「アクションセンター」が開き、通知と各種設定ボタンが一体化していました。
- **Windows 11:** 機能が2つに分離されました。
    - **クイック設定:** **音量やWi-Fi、Bluetoothのアイコン**をクリックすると開きます。音量調整、Bluetoothイヤホンの接続、明るさの調整などはここから行います。
    - **通知センター:** **日付と時刻**をクリックすると開きます。アプリからの通知やカレンダーの予定が表示されます。

**【ポイント】**

- **ショートカットキー:**
    - `Win + A`: クイック設定を開く
    - `Win + N`: 通知センターを開く
- Bluetoothイヤホンを接続する際は、`Win + A`でクイック設定を開き、Bluetoothアイコンの横の「>」をクリックすると、接続可能なデバイスが一覧表示され、素早くペアリングできます。

### **4. 便利な新機能**

Windows 11には、日々の業務、特に複数のアプリを同時に使う作業を効率化する機能が追加されています。

### **A. スナップレイアウト機能（ウィンドウの自動整列）**

複数のウィンドウ（例：ExcelとWebex、WordとブラウザのAWS画面）を同時に見ながら作業する際に非常に強力な機能です。

- **使い方:** ウィンドウの右上にある**「最大化」ボタンにカーソルを合わせる**（クリックしない）と、レイアウトの選択肢が表示されます。好きなレイアウトを選ぶだけで、ウィンドウが画面にぴったりと配置されます。
- **メリット:** これまで手動でウィンドウのサイズを調整していた手間がなくなります。特に、仕様書を見ながらドキュメントを作成したり、Azureの画面を参照しながら報告書を作成したりする際に便利です。
- **ショートカットキー:** `Win + Z`

**【機能紹介】**

### **B. スクリーンショットと画面録画の強化（Snipping Tool）**

マニュアル作成などで必要なスクリーンショットや画面録画が、標準ツールで簡単に行えるようになりました。

- **使い方:** `Win + Shift + S` のショートカットキーを押すと、Snipping Toolが起動します。
- **新機能:**
    - **画面録画:** これまで特別なソフトが必要だった画面の操作録画が、Snipping Tool内の「録画」ボタンから行えるようになりました。簡単な操作説明動画を作成するのに最適です。
    - **テキスト認識:** スクリーンショット内の文字を認識し、コピーできるようになりました（「テキスト アクション」機能）。Webページや画像内の文字をWordなどに貼り付けたい場合に便利です。
