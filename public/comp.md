### Transmit Security と PingOne の機能比較表

| 機能分野       | Transmit Security の特徴                                                                 | PingOne の特徴                                                                 |
|----------------|------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------|
| API メソッド   | 柔軟な RESTful API を提供、複数の認証方式に対応                                          | 幅広い API を提供、OAuth2 / OIDC / SAML など主要プロトコルに対応               |
| ホステッドログイン | UI カスタマイズ可、多言語・ブランド対応、MFA 設定可能                                     | 標準ログイン体験を提供、URL カスタマイズや段階的プロファイル収集に対応         |
| ボット検知     | ボットアクティビティの検出・ブロック機能を提供                                           | 拡張されたボット検出機能（PingOne Protect）、リスク評価に対応                  |
| CIAM 機能      | ユーザー登録、認証、MFA、属性情報の取得など基本 CIAM 機能を提供                            | ユーザーディレクトリ管理、SCIM 対応を含む包括的な CIAM を提供                 |
