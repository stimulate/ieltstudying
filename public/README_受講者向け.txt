SQL Training Lab 操作方法
=========================

1. ZIPファイルをPCにダウンロードしてください。

2. ZIPファイルを右クリックし、
   「すべて展開」を選択してください。

3. 展開したフォルダー内の
   Launch_SQLLab.cmd
   をダブルクリックしてください。

4. SQL Training Labが起動したら、
   上部のリストから練習問題を選択してください。

5. SQL入力欄にSQLを入力し、
   「SQL実行」をクリックしてください。

6. 解答を確認する場合は、
   「解答を表示」をクリックしてください。

7. 初期状態に戻す場合は、
   Microsoft Accessを閉じてから
   Reset_SQLLab.cmd
   を実行してください。

注意：
ZIPファイル内から直接起動せず、
必ず「すべて展開」してから実行してください。
