# AvePoint Cloud Backup 復元操作手順書

## 📘 目的

本ドキュメントは、AvePoint Cloud Backup を使用して Microsoft 365 環境のデータを復元する手順を、図解付きでわかりやすく説明することを目的としています。

---

## 👤 対象読者

- システム管理者
- ITサポート担当者
- Microsoft 365 のバックアップ・リストアを担当するチーム

---

## 🛠 使用環境

- AvePoint Cloud Backup 管理ポータル
- 対象：SharePoint / OneDrive / Exchange / Teams など
- 権限：復元操作が可能なアカウントでログイン済みであること

---

## 🔐 1. AvePoint 管理ポータルにログイン

1. 管理ポータルの URL にアクセス  
   👉 `https://www.avepointonlineservices.com/`
2. 管理アカウントでログイン

![ログイン画面](https://example.com/login_screenshot.png)

---

## 📂 2. 対象サービスを選択

1. ダッシュボードから「Cloud Backup」をクリック
2. 「バックアップの概要」から復元対象のサービスを選択  
   例：SharePoint Online、OneDrive、Exchange Online、Teams など

![サービス選択画面](https://example.com/service_selection.png)

---

## 🔍 3. 対象データの検索

1. 「復元」タブをクリック
2. 復元したい日時のバックアップデータを選択
3. ユーザー名やファイル名で検索

![バックアップ履歴と検索画面](https://example.com/backup_history_search.png)

---

## 👀 4. データをプレビューして確認

1. ファイルやメールを選択し、右クリックで「プレビュー」を選択
2. 復元対象が正しいか内容を確認

![プレビュー画面](https://example.com/preview.png)

---

## 📥 5. 復元先の指定と実行

1. 復元方法を選択：
   - 元の場所へ復元
   - 別のユーザー／別のフォルダへ復元（リダイレクト復元）
2. オプション設定（例：権限を復元するか、ファイルを上書きするか）
3. 「復元の実行」をクリック

![復元オプション選択画面](https://example.com/restore_options.png)

![復元完了画面](https://example.com/restore_complete.png)

---

## ✅ 6. 復元結果の確認

1. 「操作履歴」または「ジョブ一覧」からステータスを確認
2. 成功／失敗ログをダウンロード可能

![ジョブステータス確認画面](https://example.com/job_status.png)

---

## 🛠 7. トラブルシューティング（よくあるエラー）

| エラー内容                       | 対応方法                                         |
|----------------------------------|--------------------------------------------------|
| 復元に失敗しました（アクセス拒否） | 対象ユーザーに十分な権限があるか確認             |
| ファイルが存在しません           | 指定した日時のバックアップがあるか確認           |
| 復元後にファイルが壊れている     | 別の日付のバックアップを試すか、AvePoint サポートへ連絡 |

---

## 📌 補足事項

- リダイレクト復元を行う場合、事前に復元先ユーザーの OneDrive やフォルダの権限確認が必要です。
- 復元前には、必ず内容確認・プレビューを行ってください。

## ✅ 復元作業チェックリスト

以下のチェックリストを使用して、復元作業の各ステップを確認してください：

| **項目**                                                       | **確認** |
|---------------------------------------------------------------|:--------:|
| AvePoint 管理ポータルにアクセスし、管理アカウントでログインした |          |
| 「Cloud Backup」ダッシュボードから対象サービスを選択した         |          |
| 復元したい日時のバックアップデータを選択し、対象データを検索した   |          |
| 復元対象のデータをプレビューし、内容を確認した                   |          |
| 復元方法（元の場所または別の場所）を選択し、オプション設定を確認した |          |
| 「復元の実行」をクリックし、復元処理を開始した                   |          |
| 「操作履歴」または「ジョブ一覧」で復元結果を確認した             |          |
| 必要に応じて、復元結果のログをダウンロードした                   |          |
| トラブルシューティングガイドを参照し、問題が解決されたことを確認した |          |

Restoreの実行前に設定内容の確認画面が表示されます。ここでは、これまでに指定した各項目の概要が一覧で確認できます。

「Restore対象」の項目に表示されている青色のリンクをクリックすると、復元対象のメールアドレスを確認できます。内容に誤りがないか確認してください。

そのほかの設定項目（復元先、データ範囲、競合時の処理など）についても、意図した内容になっているかを再度ご確認ください。

すべて問題なければ、画面右下の［Restore］ボタンをクリックして処理を開始します。
Restoreを実行すると、画面右上に一時的なポップアップが表示され、復元ジョブの開始が通知されます。

その後、画面左側のサイドメニューから［Activity］ > ［Job Monitor］をクリックすると、先ほど実行したRestoreジョブのステータスや開始・終了時刻などの情報を確認できます。

さらに、ジョブ一覧に表示されているJob IDをクリックすると、復元処理の**詳細情報（処理対象、件数、エラーの有無など）**が表示されます。
詳細画面では、画面右上の「︙（三点リーダー）」メニューをクリックし、［レポートの生成］を選択することで、復元ジョブのレポートを出力することができます。
レポートの生成には多少時間がかかる場合があります。

レポートが生成されると、［Job Monitor］画面の該当ジョブの行にある右端の「︙（三点リーダー）」メニューから、［レポートのダウンロード］を選択することで、直接レポートを取得できます。
「Level」のドロップダウンリストから［Folder］を選択すると、フォルダー単位での復元対象指定が可能になります。

フォルダー名の入力は必須ではありませんが、キーワードを入力することで対象範囲を絞り込むことができます。

キーワードを入力すると、該当するユーザーのメールボックス内にある、条件に一致するフォルダーの一覧が結果として表示されます。
フォルダー名を入力しなかった場合は、該当ユーザーのメールボックス内のすべてのフォルダーが表示されます。
### Mailbox Item レベルでの条件指定

「Level」のドロップダウンから **Mailbox Item** を選択すると、**個別のメールアイテム単位での条件指定**が可能になります。

表示される検索オプションでは、以下の条件で絞り込みが可能です：

| 条件項目 | 説明 |
|----------|------|
| 件名（Subject） | メールの件名で絞り込み |
| 差出人（From） | 送信者のメールアドレスまたは名前 |
| 宛先（To） | 受信者のメールアドレスまたは名前 |
| 送信日時の範囲（Start Date ～ End Date） | 指定した期間内のメールを対象 |

---

また、**「添付ファイル付きのメールのみを対象とする（Has Attachment）」**というオプションは、初期状態では **無効（オフ）** になっています。  
この機能を有効にしたい場合は、**スイッチをクリックしてオンに切り替えてください。**

### 検索結果の表示について

検索結果には、**事前に指定した条件に一致するすべてのメールアイテム**が表示されます。

なお、**条件を何も設定しなかった場合**は、**該当のバックアップ期間内に含まれるすべてのメール**が表示されます。

### カレンダーモードでの操作方法

- 画面右上の **［Calendar Mode］** をクリックすると、表示モードをカレンダー形式に切り替えることができます。
- 画面左上の **左右の矢印ボタン** を使って、表示する**月を切り替え**ることができます。
- 復元したい日付をクリックすると、その日のバックアップデータを選択できます。

> ※ デフォルトでは、**未完了のバックアップジョブのデータは含まれません**。  
> 必要に応じて、対象データの先頭にある **「AA」チェックボックス** をオンにしてください。
>
> ### バックアップ日時を指定したあとのメールボックス選択画面について

指定した日時のバックアップに基づき、**該当のバックアップに含まれるすべてのメールボックス**が一覧で表示されます。

画面右上には、**データの表示オプション**が3つ用意されています：

| オプション | 説明 |
|------------|------|
| 不要なデータを除外（デフォルト） | **削除済みアイテムを除いたデータ**のみを表示します（初期設定） |
| 削除済みを含むすべてのデータ | バックアップ期間内の**すべてのデータ（削除済みも含む）**を表示します |
| 復元時刻以降のデータのみ | 指定した**復元時刻より後のバックアップデータのみ**を表示します |

さらに、画面右上の**検索ボックス**にキーワードを入力することで、**対象のメールボックスを素早く絞り込む**ことができます。  
また、リストをスクロールして、**手動でチェックボックスをオンにすることでも対象のメールボックスを選択可能**です。
