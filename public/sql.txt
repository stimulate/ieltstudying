**利用者の操作手順**

1. BAT ファイルをダブルクリックします。
2. 「1」を入力して Enter キーを押し、練習を開始します。
3. 終了時は Access を閉じ、メニューで「0」を選びます。

※ 練習を開始するたびに初期状態に戻ります。前回の変更は引き継がれません。

**管理者の操作手順**

1. BAT を開き、「2」を選択して管理者パスワードを入力します。
2. 「1」で編集用データベースを開き、問題やフォームを修正します。
3. 変更を保存し、Access を閉じます。
4. 管理者メニューの「2」を選び、配布用ファイル名を入力します（例：`Finance_02`）。
5. `Published` フォルダーに作成された新しい BAT を配布します。

※ 編集内容は保存されますが、配布用 BAT への反映には手順4が必要です。

**共通の注意事項**

- 操作前に、すべての Access を閉じてください。
- Access の使用中は、BAT のメニュー画面を閉じないでください。
- Access の画面を閉じても、プロセスが残る場合があります。タスクマネージャーで「Microsoft Access（MSACCESS.EXE）」が終了していることを確認してください。
- Access　データベースが開かない場合は、すべての Access と BAT を終了し、［Windows］＋［R］で `%LOCALAPPDATA%` を開いてください。必要な accdbファイル をバックアップしたうえで、`ADS\SQLTrainingV3` 内の該当する作業フォルダーを削除し、BAT を再起動してください。

# Enable Virtual Machine Platform
Enable-WindowsOptionalFeature `
    -Online `
    -FeatureName VirtualMachinePlatform `
    -All `
    -NoRestart

# Install WSL
Start-Process msiexec.exe `
    -ArgumentList '/i "wsl.msi" /qn /norestart' `
    -Wait

exit 3010
