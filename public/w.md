# AvePoint ReCenter 操作手順書（一般ユーザー向け）

## 1. 目的（Purpose）
AvePoint ReCenterは、Microsoft 365のバックアップデータ（Exchange Online、Teams、Teams チャットなど）をユーザー自身で検索・復元・エクスポートできるセルフサービスツールです。本手順書は、業務中に削除・上書きしてしまった重要なデータの迅速な復旧を支援することを目的としています。

---

## 2. 対象読者（対象者）
- Microsoft 365を日常的に利用している一般業務ユーザー
- 誤削除や誤操作によるデータの復旧を必要とする方
- IT部門の手を借りずに自己解決を目指すユーザー

---

## 3. 使用環境
- インターネット接続環境
- Microsoft 365 アカウント（Azure AD認証）
- AvePoint ReCenterの利用が組織で許可されていること

---

## 4. ログイン方法
1. Microsoft 365 にログイン
2. アプリ起動ツール（アプリランチャー）から「AvePoint ReCenter」をクリック
3. 初回ログイン時に権限の承認が求められることがあります

---

## 5. 対象サービスの選択
ウェブ画面上のメニューから対象のサービス（Exchange Online、Teams、Teams チャット）を選択してください。

サービスを選択後、復元対象データの検索画面へ移動します。

---

## 6. 対象データの検索

### カレンダーモードでの検索
1. 画面右上の「カレンダーモード」をクリックして切替  
2. 月ごとの切り替え：左上の「←」「→」で月を移動  
3. 任意の日付をクリック → その日に完了したバックアップが表示  
4. チェックボックスで「未完了のバックアップも含む」を有効化可

### キーワード検索モード
1. サービスを選択後、検索条件入力欄にキーワードを入力  
2. 件名、送信元、宛先、ファイル名などで絞り込み  
3. 添付ファイル付きのみ検索：スイッチをオンにする

---

## 7. 条件によるフィルタ（フィルターオプション）

| 条件項目 | 説明 |
|----------|------|
| 検索レベル（Level） | mailbox / folder / item から選択 |
| 送信日（期間） | カレンダーから開始・終了日時を選択（AM/PM指定） |
| フォルダ名 | 入力で一致フォルダを絞り込み可能 |
| 添付ファイル | 添付ありのメールのみ対象とする設定 |

---

## 8. 復元（Restore）・エクスポート（Export）

### データの復元（Restore）
1. 検索結果から復元したいオブジェクトを選択  
2. 画面右側に表示される「復元設定」サイドバーで以下を設定：

| 設定項目 | 内容 |
|----------|------|
| 説明欄（任意） | 復元理由などを記入可能 |
| 復元先 | デフォルトは元の場所。変更する場合は検索して選択 |
| 日付範囲 | デフォルトは全期間。任意の期間指定も可 |
| コンテナレベルの競合対応 | skip（スキップ）または merge（結合） |
| コンテンツレベルの競合対応 | skip / append / overwrite を選択 |

3. 右下の「次へ」→ 設定内容の確認  
4. 「復元」ボタンで実行

### データのエクスポート（Export）
1. 検索結果からデータを選択し、「エクスポート」ボタンをクリック  
2. エクスポート条件を選択（送信日の期間指定など）  
3. 実行後、右上に「エクスポートを開始しました」の通知  
4. 左メニューの「ジョブモニター」からステータス確認可

---

## 9. 結果確認・エクスポートデータのダウンロード

### 復元／エクスポート作業の確認方法
1. 左メニューの「アクティビティ」→「ジョブモニター」へ移動  
2. ジョブ ID をクリックで詳細を確認可能  
3. 詳細画面右上「三点リーダー（…）」からレポート出力

### エクスポートデータのダウンロード
1. ジョブモニター画面で対象のジョブ右端の「…」をクリック  
2. 「ダウンロード」を選択  
3. ZIP形式でファイルがダウンロードされます  
   ✅ **解凍パスワードは忘れずにメモ！**

---

## 10. 作業レポートの出力

- 各ジョブ詳細画面右上の「…（三点リーダー）」から「レポート出力」選択  
- CSV形式でのダウンロードが可能  
- レポートには処理対象、件数、実行者、完了時刻などが含まれます

---

## 11. トラブルシューティング（よくある問題と対処）

| 症状 | 原因 | 対処方法 |
|------|------|-----------|
| 検索結果が表示されない | 対象期間にバックアップなし | 期間指定を変更 |
| ダウンロードできない | 通信エラー／権限不足 | ブラウザ再起動、管理者に確認 |
| 復元先が表示されない | フィルター条件が厳しすぎる | 検索キーワードを緩める |

---

## 12. 注意事項

- データは復元先の空き容量に依存します  
- 復元先が共有環境の場合、意図しない上書きに注意  
- 過去の削除データの保持期間に制限がある場合があります（管理者に確認）

## 14. 復元作業前のチェックリスト ✅

| チェック項目 | 確認内容 |
|--------------|----------|
| 対象データ | バックアップに含まれているか |
| 検索条件 | 正しい期間・キーワードを指定しているか |
| 復元先 | 指定先が正しい／容量に余裕があるか |
| ログイン情報 | 正しい Microsoft 365 アカウントでログイン済みか |
| 競合設定 | 上書き設定による事故防止の確認 |

以上で ReCenter によるデータ復元の操作手順は完了です。  
セルフサービスでの復元に不安がある場合は、必ず IT 担当者に相談してください。

検索ボックスにジョブIDの全体または一部を入力するか、右側の「フィルター」ボタンをクリックして、表示されるサイドバーで「オブジェクトタイプ」「ジョブタイプ」「ステータス」「期間」などの項目にチェックを入れることで、関連するジョブを検索したり、結果の範囲を絞り込むことができます。


左側のメールボックス前にある矢印をクリックしてフォルダを展開し、該当フォルダを選択すると、右側にそのフォルダ内のすべてのメールが表示されます。そこから復元またはエクスポートしたいメールを選んでください。
