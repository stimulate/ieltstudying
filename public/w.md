# AvePoint ReCenter データ復元操作手順書（一般ユーザー向け）

## 1. はじめに（目的と対象者）

本手順書では、AvePoint ReCenter サービスを利用して、Microsoft 365（Exchange Online、Teamsなど）のデータを復元する操作方法を説明します。ReCenterはエンドユーザー自身が Exchange Online のメールやファイル、Teams のチャット・チャンネルメッセージなどをWebポータル上で検索・復元できるセルフサービス型のリストアツールです。IT部門の負担を減らし、業務の中断を最小限に抑えることが目的です。

対象は一般の業務ユーザー（IT担当者以外）で、誤って削除してしまったメールやファイル、チャット履歴などを自力で復旧したい方を想定しています。復元操作を開始する前に、必要なアクセス権や復元対象データがバックアップに含まれているかをご確認ください。

## 2. ReCenter のアクセス方法

1. Microsoft 365 にサインイン  
2. 画面右上のアプリ起動ツール（□が9つ並んだアイコン）をクリック  
3. 「AvePoint Online Services」→「すべてのアプリ」→「ReCenter」を選択  
4. 組織によっては IT 管理者から ReCenter の直接リンクが提供される場合もあります

## 3. 復元対象の選択（Exchange Online、Teams、Teams チャット）

復元可能なデータ種別：

- **Exchange Online**：メール、予定表など
- **Microsoft Teams**：チャネル投稿、共有ファイル（SharePoint経由）
- **Teams チャット**：1対1・グループチャットメッセージ、添付ファイル

## 4. 検索・絞り込み方法（カレンダー／キーワード／フィルター）

- **カレンダーで期間指定**：対象期間を指定して検索結果を絞り込み
- **キーワード検索**：件名、本文、ファイル名などを入力
- **フィルター指定**：送信者、ファイルタイプ、サイズなどで条件追加

## 5. 各復元レベルごとの手順

### メールボックス単位の復元

1. 対象ユーザーの Exchange Online を選択  
2. 「…」メニュー →「リストア」選択  
3. 復元先確認 → 実行

### フォルダー単位の復元

1. 対象フォルダーを開くまたは検索  
2. フォルダーを選択 →「…」→「リストア」  
3. 復元先確認 → 実行

### アイテム単位の復元

1. メールやファイルを検索して選択  
2. プレビューで内容確認（必要時）  
3.「…」→「リストア」選択  
4. 復元先指定 → 実行

## 6. レポート・ジョブ確認・ダウンロード

- 「ジョブ」画面でステータス確認（成功・失敗など）
- 「レポート」画面で円グラフや詳細レポート確認・CSV出力可能
- ダウンロード方式で復元した場合は ZIP/PST 形式で取得  
  - ダウンロードリンクから保存し、**解凍パスワードの保存を忘れずに！**

## 7. よくある質問・注意点

### Q1. 添付ファイルだけを探すには？
- ファイル名や拡張子で検索
- 「ファイル」カテゴリを選択して絞り込み

### Q2. 復元前に中身を確認できますか？
- はい、プレビュー機能で確認可能

### Q3. その他の注意点
- 復元先容量や対象の誤選択に注意
- 結果が多いときはフィルター追加

## 8. チェックリスト（復元実行前の確認事項）

| チェック項目 | 確認内容 |
| --- | --- |
| 復元対象データ | バックアップに含まれているか確認 |
| 復元日時範囲 | 対象の日時が正しいかカレンダーで指定 |
| 復元先 | メールボックスやフォルダーが正しいか |
| 権限・ログイン | 復元対象・復元先への権限確認 |
| ネットワーク環境 | 通信環境が安定しているか |
